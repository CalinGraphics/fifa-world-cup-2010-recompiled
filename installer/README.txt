2010 FIFA World Cup South Africa: Recompiled
============================================

An unofficial native PC port of the Xbox 360 game. No game files are included:
you need your own Xbox 360 copy of the game (Europe disc, En/Es/Nl).

Getting started
---------------
1. Run Launcher.exe. If Windows says "Windows protected your PC", choose
   More info, then Run anyway (the program isn't code-signed).
2. Click "Choose disc image" and pick your Xbox 360 disc image, or drop it on the
   window ("Game folder" works for a folder with default.xex and fifadllzf.xex).
   The launcher checks that it is the right version.
3. Press KICK OFF.

Launcher pages
--------------
Play      Your game copy and a summary of your settings
Display   Window, borderless or exclusive fullscreen; window size; V-Sync;
          frame rate (60, or 30 everywhere); FPS counter
Graphics  Render resolution: 720p (original), 1440p or 4K; texture filtering
Controls  Controller (Xbox, PlayStation, others) or keyboard
About     Saves and logs folder, desktop shortcut, reset settings

Keyboard
--------
Move                     W A S D
Short pass (A)           Space
Shoot (B)                Backspace
Lob / cross (X)          L
Through ball (Y)         P
Sprint (RT)              E
Pace control (LT)        Q
Player run / finesse     1 / 3   (LB / RB)
Skill moves              Arrow keys (right stick)
D-pad                    Shift + arrow keys
Pause / Back             Enter / Tab
FPS counter on / off     F2

Alt+F4 quits. The game saves automatically.

Files
-----
Settings, saves, logs and the shader cache go to
%LOCALAPPDATA%\FIFA World Cup 2010 Recompiled
Create an empty portable.txt next to Launcher.exe to keep them in a "userdata"
folder here instead.

Requirements
------------
Windows 10 or 11 (64-bit), a Direct3D 12 graphics card with current drivers.
